# qWDTT

qWDTT — Android-приложение для подключения к собственному VPS через TURN-инфраструктуру звонков VK.

Приложение создаёт системный VPN-туннель на телефоне, передаёт зашифрованный трафик через VK TURN и выпускает его в интернет через ваш сервер. Для сети такое соединение похоже на медиатрафик звонка WebRTC, а не на обычное прямое подключение к VPN-серверу.

## Две сборки

| | qWDTT | qWDTT Client |
|---|---|---|
| APK в релизе | `qwdtt-<версия>-<abi>.apk` | `qwdtt-client-<версия>-<abi>.apk` |
| Идентификатор | `net.qwdtt.client` | `net.qwdtt.client.lite` |
| Вкладка «Серверы», установка на VPS, админ-панель | есть | нет |
| Подключение, профили, обход, логи | есть | есть |

qWDTT Client — сборка для тех, кому выдали готовый профиль: она умеет только
подключаться. Админ-часть в этот APK не попадает вовсе, включить её в настройках
нечем. Идентификаторы приложений разные, поэтому обе сборки спокойно живут на
одном телефоне рядом и обновляются независимо.

## Быстрый старт

1. Скачайте APK в разделе [Releases](https://github.com/Wumurt/proxy-turn-vk-android/releases) — `qwdtt-…` для полной версии или `qwdtt-client-…`, если сервер настраивает кто-то другой.
2. Добавьте VPS на вкладке «Серверы» и выполните установку серверной части (только в полной версии).
3. Создайте профиль подключения или импортируйте готовую ссылку.
4. Добавьте хеш звонка VK.
5. Нажмите «Подключить» и разрешите Android создать VPN-соединение.

## Сборки

- стабильные подписанные версии публикуются в [GitHub Releases](https://github.com/Wumurt/proxy-turn-vk-android/releases);
- тестовые debug-сборки ветки `develop` доступны в [GitHub Actions](https://github.com/Wumurt/proxy-turn-vk-android/actions/workflows/android-debug.yml).

## Происхождение проекта

Этот репозиторий — форк проекта [qWDTT](https://github.com/SpaceNeuroX/proxy-turn-vk-android) от разработчика SpaceNeuroX. Оттуда взяты приложение, серверная часть и значительная доля клиентской и серверной логики.

qWDTT, в свою очередь, был построен на исходниках Android-приложения и серверной части оригинального проекта [WDTT](https://github.com/amurcanov/proxy-turn-vk-android) от разработчика amurcanov. Оригинальный репозиторий сейчас архивирован.

Проект развивается самостоятельно и не является официальным продолжением или новым релизом ни qWDTT, ни WDTT.
